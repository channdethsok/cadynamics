## 1. Motivation: Pausing Neural Modeling for Mathematical Rigor

Prior to training any neural world model, JEPA predictor, or visual/geometric encoders, the underlying offline data must be mathematically grounded. 

In parametric CAD, geometry is not static; it is generated causally through an ordered sequence of construction operations:
$$\tau = (S_0, A_0, S_1, A_1, \ldots, A_{K-1}, S_K)$$

### 1.1 Strict Grounding Invariants Enforced:
1. **Empty Workspace Base State ($S_0$)**:
   $S_0$ is explicitly the empty workspace (0 faces, 0 edges, empty UV grids, and a neutral uniform canvas render).
2. **Deterministic State Transition**:
   $$S_{k+1} = F(S_k, A_k)$$
   Every state $S_k$ is extracted from the true intermediate solid immediately after operation $A_{k-1}$ executes.
3. **No Proxy Representations**:
   Never use final-solid renders (`image_0..7`) or final STEP geometry to approximate intermediate states $S_k$ ($k < K$).
4. **Zero Intermediate Disk Overhead**:
   Never write intermediate `.step`, `.stl`, `.png`, or temporary geometry files to disk. All tessellation, B-Rep traversal, and isometric rendering occur strictly in-memory.
5. **No Future Leakage**:
   No normalization factor, bounding box, or reference entity from future states $S_{k+1..K}$ may contaminate $S_k$ or $A_k$.
6. **Robust Process Isolation**:
   Isolate OpenCASCADE and VTK allocators using Python `multiprocessing` with explicit `spawn` context and strict 15-second per-part timeout protection.

## 3. Module Breakdown & Technical Innovations

### 3.1 Runtime CadQuery Method Interception (`instrumentation.py`)
CadQuery code is heavily fluent and method-chained:
```python
result = cq.Workplane("XY").box(40, 30, 5).faces(">Z").workplane().circle(5).cutThruAll()
```
Splitting Python AST statements naively misses intermediate geometry. Instead, `CadQueryRuntimeTracer` dynamically wraps all solid-modifying methods (`extrude`, `cut`, `hole`, `fillet`, `chamfer`, etc.) on `cq.Workplane` at runtime:
1. **Pre-Operation Hook**: Inspects active workplane, pending sketch wires in `ctx.pendingWires`, and selected entities before CadQuery consumes them.
2. **Operation Execution**: Invokes the underlying CadQuery method.
3. **Post-Operation Hook**: Extracts the resulting `TopoDS_Shape` into $S_{k+1}$ in memory.
4. **Restoration**: Cleanly restores all monkey-patched methods upon exit.

### 3.2 Topological Entity Matching via `IsSame` (`action_extractor.py`)
In OpenCASCADE, Python entity IDs and equality operators (`==`) do not persist across method invocations. To anchor actions to prior geometry $S_k$, `_extract_references` maps selected faces/edges to $S_k$ face graph indices using native topological identity:
```python
if occ_face.IsSame(prev_face_map.FindKey(k)):
    matched_face_idx = k - 1
```
Multi-entity selections (e.g. filleting multiple edges simultaneously) are fully preserved as dynamic arrays `[M, 3]` alongside the fixed 12-D action summary.

### 3.3 Safe In-Memory B-Rep Extraction (`occ_extractor.py`)
Extracts rich geometric attributes without writing intermediate STEP files:
- **32-D Face Surface Features**: Surface type (Plane, Cylinder, Cone, Sphere, Torus, BSpline, etc.), surface area, centroid, bounding box, Gaussian & mean curvatures, and trim loop counts.
- **Trimmed UV Surface Grids `[N, 7, 16, 16]`**:
  - UV bounds evaluated strictly via `OCP.BRepTools.BRepTools.UVBounds_s` (avoiding $\pm\infty$ on planar primitives).
  - Evaluates 3D surface point $[X, Y, Z]$, surface normal $[N_x, N_y, N_z]$ (flipped if `TopAbs_REVERSED`), and boundary mask $\in \{0, 1\}$ using `BRepTopAdaptor_FClass2d`.
- **Bidirectional Face-Adjacency Graph (FAG)**: Evaluates shared topological edges between faces to generate PyG-compatible `brep_edge_index` `[2, Num_Edges]`.

### 3.4 In-Memory Offscreen Rendering (`renderer.py`)
- Leverages PyVista offscreen renderer directly from `shape.val().tessellate(0.1)` in memory.
- Isometric projection (`azimuth=45`, `elevation=30`) rendered at $224 \times 224$ pixels.
- Zero disk reads or writes; returns pure `torch.uint8` tensor `[3, 224, 224]`.
