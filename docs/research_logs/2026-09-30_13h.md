## 2. Transition Pair Formulation: $(S_t, A_t, S_{t+1})$

For any part with $T$ construction steps, a transition index $t \in [0, T-2]$ is randomly sampled during training.

### 2.1 Current State ($S_t$)
- `image`: Tensor `[3, 224, 224]` from `renders/render_t.png` or `image_{t % 8}` (ImageNet normalized: $\mu=[0.485, 0.456, 0.406]$, $\sigma=[0.229, 0.224, 0.225]$).
- `brep_nodes`: FloatTensor `[Num_Faces_t, 32]` extracted B-Rep face surface features.
- `brep_edge_index`: LongTensor `[2, Num_Edges_t]` Face-Adjacency Graph (FAG) connectivity.
- `history_cmd_ids`: LongTensor `[t]` discrete command IDs for operations executed up to step $t$.

### 2.2 Action ($A_t$)
- `cmd_id`: LongTensor `[]` scalar discrete index from our 11-token vocabulary:
  ```python
  COMMAND_VOCAB = [
      'SKETCH_LINE',    # 0: line, lineTo, vLine, hLine, polyline, rect, polygon, slot
      'SKETCH_ARC',     # 1: radiusArc, threePointArc, sagittaArc, tangentArc, arc, spline
      'SKETCH_CIRCLE',  # 2: circle, sketch_circle
      'EXTRUDE',        # 3: extrude, twistExtrude, sweep, loft
      'CUT',            # 4: cut, cutBlind, cutThruAll, holeThruAll
      'FILLET',         # 5: fillet
      'CHAMFER',        # 6: chamfer
      'REVOLVE',        # 7: revolve
      'PAD',            # 8: pad, box, cylinder, sphere, wedge
      'HOLE',           # 9: hole, cboreHole, cskHole, csk_face_hole
      'OTHER',          # 10: unmapped / setup ops (workplane, faces, edges, measures)
  ]
  ```
- `params`: FloatTensor `[12]` continuous parameters (coordinates, dimensions, radii, angles, depths), normalized into $[-1, 1]$ via clipping/scaling, zero-padded to length 12.
- `param_mask`: BoolTensor `[12]` binary mask indicating which continuous parameters are active for this command.

### 2.3 Next State ($S_{t+1}$)
- `image`: Tensor `[3, 224, 224]` from `renders/render_{t+1}.png` or `image_{(t+1) % 8}` (ImageNet normalized).
- `brep_nodes`: FloatTensor `[Num_Faces_{t+1}, 32]` extracted B-Rep face surface features.
- `brep_edge_index`: LongTensor `[2, Num_Edges_{t+1}]`.

## 3. B-Rep Surface Feature Specification (32 Dimensions)

Face surface features are extracted using OpenCASCADE (`pythonocc-core` / `OCC.Core`):

| Index Range | Dimension | Description |
|---|---|---|
| `[0:8]` | 8 | Surface type one-hot: Plane, Cylinder, Cone, Sphere, Torus, BSpline/Bezier, Extrusion/Revolution, Other |
| `[8]` | 1 | Face surface area (`BRepGProp.SurfaceProperties`) |
| `[9:12]` | 3 | Centroid coordinates $(cx, cy, cz)$ (center of mass) |
| `[12:15]` | 3 | Unit normal vector $(nx, ny, nz)$ at midpoint UV parameter |
| `[15:18]` | 3 | Bounding box dimensions $(dx, dy, dz)$ (`Bnd_Box`) |
| `[18:20]` | 2 | Topological counts: wire loop count, boundary edge count |
| `[20]` | 1 | Face orientation flag (+1.0 forward, -1.0 reversed) |
| `[21:23]` | 2 | UV domain span lengths $(\Delta u, \Delta v)$ |
| `[23:26]` | 3 | Diagonal elements of matrix of inertia $(I_{xx}, I_{yy}, I_{zz})$ |
| `[26]` | 1 | $\log(1 + \text{area})$ |
| `[27:29]` | 2 | Aspect ratios: $dx / (dy + \epsilon)$, $dy / (dz + \epsilon)$ |
| `[29]` | 1 | Diagonal bounding box length $\sqrt{dx^2 + dy^2 + dz^2}$ |
| `[30]` | 1 | Curvature flag (0.0 if planar, 1.0 if curved) |
| `[31]` | 1 | Multi-loop / trimming boundary indicator (1.0 if wires > 1) |

## 4. Batch Collation (`collate_transition_batch`)

Handles variable numbers of faces and edges across samples in each batch:
- **`current_state['image']`**: `[B, 3, 224, 224]`
- **`next_state['image']`**: `[B, 3, 224, 224]`
- **`action['cmd_id']`**: `[B]`
- **`action['params']`**: `[B, 12]`
- **`action['param_mask']`**: `[B, 12]`
- **`current_state['history_cmd_ids']`**: `[B, Max_History_Len]` padded tensor with `history_lengths [B]` and `history_mask [B, Max_History_Len]`
- **B-Rep Graph Batching**:
  - `torch_geometric.data.Batch` object in `brep_graph`
  - Packed node features `brep_nodes`: `[Total_Faces, 32]`
  - Offset edge index `brep_edge_index`: `[2, Total_Edges]`
  - Graph assignment vector `brep_batch`: `[Total_Faces]`
