## 1. Output Directory Restructuring & Split Partitioning

To prevent data contamination and ensure out-of-the-box compatibility with PyTorch Lightning and standard distributed data loaders (`DistributedSampler`), the preprocessing output directory has been restructured:

```text
data/processed_data/
├── train/
│   ├── shard_0000.pt
│   ├── shard_0001.pt
│   └── ...
└── val/
    ├── shard_0000.pt
    └── ...
```

### 1.1 Dual Routing Architecture
The pipeline in [`scripts/preprocess_intermediate_states.py`](file:///home/onyxia/work/cadynamics/scripts/preprocess_intermediate_states.py) implements automated split routing:

1. **Explicit Source Splits**:
   When the source dataset provides dedicated split partitions (e.g. `data/zero_to_cad_100k/data/{train,val,test}`), the preprocessor automatically routes trajectories into corresponding subdirectories:
   - `--split val` $\rightarrow$ reads `data/val/*.parquet` $\rightarrow$ writes to `data/processed_data/val/shard_XXXX.pt`
   - `--split train` $\rightarrow$ reads `data/train/*.parquet` $\rightarrow$ writes to `data/processed_data/train/shard_XXXX.pt`
   - `--split all` $\rightarrow$ reads all splits and partitions them simultaneously into their respective subfolders.

2. **Deterministic Hash Routing for Unified Pools**:
   When reading from single unified pools lacking pre-existing partition folders, the pipeline computes a deterministic MD5 hash of the unique `part_id` (`uuid`):
   ```python
   def deterministic_split(part_id: str, train_ratio: float = 0.9) -> str:
       h = int(hashlib.md5(part_id.encode("utf-8")).hexdigest()[:8], 16)
       return "train" if (h % 100) < int(train_ratio * 100) else "val"
   ```
   - Guarantees exactly ~90% `train` / ~10% `val` split.
   - 100% deterministic and stateless across multi-worker jobs, preventing any cross-split leakage.

## 2. SymLog Normalization for Continuous CAD Metric Parameters

### 2.1 The Problem with Linear and Standard Log Scaling in CAD

Parametric CAD models inherently exhibit **extreme multi-scale dynamic range**:
- Fine detail features (e.g., chamfers, fillets, thin walls): $0.1\,\text{mm} - 1.0\,\text{mm}$
- Nominal features (e.g., bolt holes, cutouts, steps): $5\,\text{mm} - 50\,\text{mm}$
- Global dimensions (e.g., base extrusions, enclosures, beams): $200\,\text{mm} - 1500\,\text{mm}$

| Scaling Strategy | Behavior on $0.2\,\text{mm}$ Chamfer | Behavior on $1000\,\text{mm}$ Extrusion | Behavior on Negative Depth ($-25\,\text{mm}$) | Failure Mode |
|---|---|---|---|---|
| **Linear Min-Max** $[0, 1500]$ | $0.2 / 1500 = 0.00013$ | $1000 / 1500 = 0.667$ | Undefined / Clamped | Sub-millimeter features vanish into numerical precision floor; gradients for fine details are killed. |
| **Standard $\ln(x)$** | $\ln(0.2) = -1.609$ | $\ln(1000) = 6.908$ | $\ln(-25)$ **undefined / NaN** | Crashes on non-positive values; singular gradient as $x \to 0^+$ ($\frac{d}{dx}\ln(x) = \frac{1}{x} \to \infty$). |
| **SymLog** | $+0.182$ | $+6.909$ | $-3.258$ | **None**. Smooth, bounded, symmetric, zero-centered, and handles negative values seamlessly. |

### 2.2 Mathematical Definition of SymLog & SymExp

The **Symmetric Logarithm (SymLog)** transform (Hafner et al., 2023) maps metric parameters $x \in \mathbb{R}$ into neural representation space $y \in \mathbb{R}$:

$$\operatorname{symlog}(x) = \operatorname{sign}(x) \cdot \ln(1 + |x|)$$

Its inverse, the **Symmetric Exponential (SymExp)** transform, un-normalizes neural predictions back to physical CAD millimeters:

$$\operatorname{symexp}(y) = \operatorname{sign}(y) \cdot (\exp(|y|) - 1)$$

### 2.3 Mathematical Properties for Neural CAD Modeling

1. **Linear Behavior Near Zero**:
   $$\lim_{x \to 0} \frac{\operatorname{symlog}(x)}{x} = 1, \quad \left.\frac{d}{dx}\operatorname{symlog}(x)\right|_{x=0} = 1$$
   Unlike standard $\ln(x)$, the derivative at $x=0$ is strictly $1.0$, preventing gradient explosions for tiny offsets.
2. **Logarithmic Compression at Large Scales**:
   For $|x| \gg 1$, $\operatorname{symlog}(x) \approx \operatorname{sign}(x) \ln(|x|)$. A $1000\,\text{mm}$ extrusion maps to $6.91$, remaining well within the active linear regime of standard neural layers (MLPs, Transformers).
3. **Exact Invertibility**:
   $$\operatorname{symexp}(\operatorname{symlog}(x)) = x, \quad \forall x \in \mathbb{R}$$
   Verified numerically across all floating-point precisions ($|x - \hat{x}| < 10^{-5}$).
4. **Preservation of Sign and Direction**:
   $$\operatorname{symlog}(-x) = -\operatorname{symlog}(x)$$
   CAD operations with signed directions (e.g., negative extrusions, reverse cuts) preserve their directional semantics without requiring separate sign flags.
